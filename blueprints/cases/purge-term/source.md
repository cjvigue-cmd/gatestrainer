# Quill 0.4 release notes

Quill now starts in 2.1 seconds, down from 3.4. Run `quill --doctor` to check your setup, or read https://example.com/docs/setup first.

- Quill's gate library has 23 blueprints.
- The installer asks for {licence_key} once.

Thanks to the 14 testers who tried Quill this month.
